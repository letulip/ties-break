# Code Quality – KISS, DRY, Dead Code, Complexity

## Verdict

This codebase is in considerably better shape than its headline file sizes suggest. The scary numbers are half narrative: world.ts is 2661 code lines out of 5521, and the giant diary/protocol files are mostly licensed text pools and type definitions. Typing is genuinely strict (zero real `any` in src/, clean `vue-tsc -b`, 11 guarded non-null assertions), tuning constants live in one documented hub (ECONOMY), layering is stated and honored, and the CSS DRY audit was real, mechanically verified work whose rulings verifiably landed. The debt that remains is concentrated in the UI layer: money formatting is re-implemented 15 times with a same-name/different-unit trap, the Money screen hand-copies an engine constant, App.vue repeats one watermark pattern four times, and MatchViewer/SeasonScreen are monoliths. The three actions that matter most: (1) move money formatting into shared/format.ts and delete all 15 copies – this is a display-honesty risk in the honest-economics game, not a style nit; (2) import STARTING_FUNDS_CENTS in MoneyScreen instead of the 'must match' copy; (3) write down the global-vs-scoped CSS ownership rule before the audit's discipline finishes eroding.

## Strengths

- **Strict TypeScript, for real.** Every grep hit for `: any` / `as any` in src/ is a comment or the CSS word 'anywhere'. Non-null assertions total 11, each locally guarded (e.g. world.ts:1949-1950 behind `knockLive`); `as unknown as` appears only at the worker/migrations boundary where it belongs (sim.worker.ts:49, migrations.ts:242, 397, 812). tsconfig.app.json runs strict + noUnusedLocals + noUnusedParameters and the build is clean.
- **Balance numbers have one home.** ECONOMY (economy.ts:72) is the declared 'ручки регулировки' surface, with RNG-draw-count discipline documented in its header; match-model constants are named (point.ts:8-55). A scan for anonymous inline decimals in world.ts arithmetic came back empty – rare for a balance-heavy game.
- **Layering is stated once and holds.** engine/shared/viz import nothing from components/stores; no DOM or console access in the engine; the dependency rule is written at world.ts:48-56. Runtime deps: vue + pinia, nothing else.
- **Decision-record culture instead of TODO rot.** Zero TODO/FIXME in src/. Owner rulings sit at the exact lines they govern (style.css:329-334, weekGrid.ts header), which is why 50-66% of the big engine files is comment – expensive to read linearly, priceless in a blame view.
- **The css-dry-audit was executed, not shelved.** All five owner rulings landed and are checkable: `--accent-wash`/`--accent-fill` (style.css:80-81), `--label-size`/`--label-track` (92-93), `--on-lime` (101), `--warning` (199); the dead `.condition-cell`/`.surface-note` rules are gone.
- **The ui/ kit is genuinely used** (Card 12 importers, IconButton 12, PrimaryPill 9, ScreenShell 8), scoped CSS is token-driven, and a mechanical scan found only 7 identical 4+-declaration rule bodies across all 6657 scoped lines.
- **No orphan modules** – every engine/viz module sampled has live importers.

## Findings

**[HIGH] Money formatting re-implemented 15 times, with a unit trap** – `formatSigned` is byte-identical in WeekRecapCard.vue:229, SeasonSummaryDialog.vue:37, SeasonHistoryTable.vue:51 and MoneyScreen.vue:100; `formatDollars(cents)` is copied in TierGuide.vue:31, PlanWeekSheet.vue:40, InjuryStopDialog.vue:67, CalendarScreen.vue:234, CoachMarketScreen.vue:51, SeasonScreen.vue:72 and SeasonHistoryTable.vue:56; `formatFunds` in MoneyScreen.vue:95 + HomeScreen.vue:321; OfferLetter.vue:100 and InboxSheet.vue:39 inline the same expression. The trap: MoneyScreen.vue:105 declares `formatDollars(dollars: number)` taking **dollars** while six sibling functions of the same name take **cents**. One code move between screens away from a x100 display bug. src/shared/format.ts ('Shared display helpers') exists and holds only name/rank helpers. Fix: add `formatDollars`/`formatSigned`/`formatFunds` (cents-in, one contract) to shared/format.ts, delete every local copy, rename the MoneyScreen dollars-in one out of the collision.

**[MEDIUM] MoneyScreen hand-copies STARTING_FUNDS_CENTS** – MoneyScreen.vue:91-93 hard-codes `{ wealthy: 120_000, middle: 25_000, working: 8_000 }` with a 'must match src/engine/world.ts STARTING_FUNDS_CENTS' comment. The constant is exported (world.ts:445) and the UI already imports engine constants (SeasonScreen imports ECONOMY). Retune the engine and the Money screen silently lies. Fix: import and divide by 100.

**[MEDIUM] world.ts is the everything-mutator file; tickWeek's step labels have fossilized** – 161 functions covering finance, injuries, knocks, coaching, vacations, sponsors, tournament finalization, entry gates and snapshot assembly; sibling modules (knock.ts, coach.ts, condition.ts) hold only pure helpers. tickWeek (world.ts:4171-4500, 330 lines) and toSnapshot (5259-5521) are the giants, and the step naming has accreted into '0a00', '0a0c-bis (30.07, MOVED 01.08)', '1c-w4', '0a0-inbox (v32)' (4174-4258). The RNG-draw-order constraint genuinely pins step *order*, and comments carry the rationale – but it does not pin *file membership*. Fix direction: extract the cohesive clusters world.ts already delimits (injury/knock block ~1900-2330, sponsor/kit block ~3050-3360, snapshot assembly 5155-5521) into modules that take `world` as a parameter, exactly as economy.ts already did for constants; renumber tickWeek's steps once (1..n with a table of contents) since git history preserves the archaeology.

**[MEDIUM] MatchViewer.vue and SeasonScreen.vue are monolith components** – MatchViewer (2235 lines, 148 top-level bindings) contains, per its own banners: canvas/DPR (83), playback controls (109), playback clock (131), ends-swap (157), run-on (166), serve-speed (185), music ducking (275), sound matrix (286), out-calls (310), stop-on-hide (586), readout (773), momentum (914), commentary (993), shout (1004), controls (1122). Each section is already composable-shaped. SeasonScreen has 125 bindings and 30+ imports spanning entries, planner, vacations, practice, exhibition sandbox, replay and tier guide. Fix: peel the self-contained sections into composables (useMatchAudio, useMatchReadout, useMomentum) and child components; no behavior change required.

**[MEDIUM] App.vue: one badge pattern, four copies** – the 'seen watermark' subsystem (localStorage key fn + ref + has-new computed + markSeen + tab watches) is pasted for Season (App.vue:220-240), This-week (242-260), News (397-442) and Trophies (444-502), ~120 lines with small divergences already visible. Fix: `useSeenWatermark(key, latest)` composable, four call sites.

**[MEDIUM] Global/scoped CSS split-brain, and the audit's premise is stale** – the U-wave (from dfd739e, 29.07) moved screens onto 6657 lines of scoped CSS while docs/specs/css-dry-audit.md still opens with 'not one `<style>` block anywhere else in src/'. Today 13 class names are defined in **both** sheets: `.event-art`'s img rule sits in style.css:1569 while its box rule is scoped in SeasonScreen.vue:1430; `.tf-sub` is declared in style.css:1900 and extended in TournamentFlow.vue:1143; `.venue-art`, `.week-art`, `.back-link`, `.recap-*` similarly. Shared idioms like `.ph-name` (style.css:2116) are consumed from four components' templates with the rule invisible from any of them. Fix: one paragraph in the audit (or DESIGN-SYSTEM.md) stating the ownership rule – shared idioms live in style.css, screen-privates live scoped, nothing is defined in both – then move the 13 stragglers to one side.

**[MEDIUM] Every load re-simulates the whole career** – restoreRng (sim.worker.ts:64-69) ticks a probe world once per elapsed week to restore the main RNG position, on all three load paths (237, 245, 276). tickWeek includes canonical AI brackets, so load time grows linearly with career length; the only tracker is the comment 'Cheap now; Phase 1+ will persist stream state properly'. Fix: persist the draw counter (the stream is already reconstructible by count), or at minimum give the cliff a ticket with a week-count threshold.

**[LOW] Replay recipe copy-pasted 3x** – MatchReplay.vue:20-29, PracticeFlow.vue:63-72, TournamentFlow.vue:507-511 each rebuild `{surface, tour: JUNIOR_TOUR, seed: m.seed ?? ''}` and run simulateMatch+annotateMatch; the engine holds a fourth copy (world.ts:2850). Divergence means a replay that differs from the recorded result. Fix: one `reannotate(match)` beside the engine.

**[LOW] Worker boilerplate** – 23 identical `if (!world) throw` guards and 22 `await autosave(world); return snapshotMsg(...)` tails across 31 case arms (sim.worker.ts). A `withCareer(fn)` wrapper halves the file.

**[LOW] Dead/needlessly-public exports** – `kidDomesticPoints` (world.ts:4506) has zero call sites anywhere; 13 radar.ts constants (EVIDENCE_PER_UNIT:124, TENURE_HALF_WEEKS, TRAINING_STEP, ...) and five world.ts functions (radarViewOf, practiceForWeek, kidBirthYear, outgrewTier) are exported but used only in their own file. Delete the dead one, un-export the rest.

**[LOW] Doc drift in the audit itself** – css-dry-audit.md:218-219 says the ring track resolved to 0.18; style.css:329-334 records the owner's actual ruling of 0.12 (with his quoted words) and lands the change on Home. The sheet is right; the spec was never updated.

**[LOW] No linter** – package.json runs only vue-tsc + vitest. Discipline currently substitutes, but nothing mechanically prevents the first `any`, unused export, or console.log from landing.

**[LOW] Deliberate mirrored predicates** – timeline.ts:46-59 mirrors MatchViewer's 'ooh' test 'kept in sync deliberately'; the friendly-match lookup is written three slightly different ways (App.vue:607, WeekRecapCard.vue:347, SeasonScreen.vue:709). Both extractable in minutes.

## Recommendations

1. **Now, cheap, highest value:** consolidate money formatting into shared/format.ts (one cents-in contract), delete the 15 copies, and kill the `formatDollars(dollars)` name collision (MoneyScreen.vue:105). Import STARTING_FUNDS_CENTS in MoneyScreen. Both are afternoon-sized and protect the economics pillar.
2. **Next wave:** extract App.vue's `useSeenWatermark` and the shared `reannotate(match)` helper; collapse the worker's `withCareer` boilerplate. All three are mechanical and test-safe.
3. **Write the CSS ownership rule** (shared idioms global, screen-privates scoped, never both) into css-dry-audit.md or DESIGN-SYSTEM.md, fix the 13 dual-defined classes, and correct the stale 0.18/0.12 ring-track paragraph while in there.
4. **Plan, don't rush:** split MatchViewer's audio/readout/momentum sections into composables, and peel world.ts's already-delimited clusters (injury/knock, sponsor/kit, snapshot assembly) into modules. Renumber tickWeek's steps once.
5. **Add ESLint** with a minimal config (no-explicit-any, no-console, no-unused-vars aligned with tsc) so today's discipline becomes tomorrow's gate.
6. **Give restoreRng's full-career replay a ticket** with a measured threshold (e.g. load time at week 300) so the 'Phase 1+' promise has an owner.
