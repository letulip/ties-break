# Research

These documents contain market, tennis, economy, injury, ranking, and technical evidence used to
form product and balance decisions. They are evidence, not runtime truth.

Before external publication or a new calibration decision, verify the source date, jurisdiction,
competition level, population, and whether a later governing rule or dataset supersedes it. Raw
research captures remain provenance material and should not be loaded for ordinary implementation
tasks.
