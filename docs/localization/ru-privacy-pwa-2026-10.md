# RU-13C – политика конфиденциальности и установка PWA

Все русские строки ниже – `DRAFT`, кроме утверждённого названия продукта. Источники: `PRIVACY.md`, `index.html:2-12`, `vite.config.ts:174-181`, ссылка About в `MoreScreen.vue`. Это перевод действующей политики, **не** обещание будущей сетевой архитектуры. Перед публикацией русской версии юридические и технические факты нужно проверить по текущей сборке.

## 1. Метаданные и языковая граница

| Источник | Предложение для `ru` | Примечание |
| --- | --- | --- |
| `<html lang="en">` | `<html lang="ru">` только в русской выдаче | Атрибут страницы должен совпадать с фактическим языком интерфейса; глобально заменять его нельзя, пока английский режим остаётся доступным. |
| `<title>Ties Break</title>` | `Ties Break: Ace Parent` | Название продукта не переводится; при одном общем HTML можно оставить нейтральное `Ties Break`. |
| manifest `name: 'Ties Break: Ace Parent'` | `Ties Break: Ace Parent` | Утверждённая марка. Не вставлять кириллический подзаголовок в название установленного приложения без отдельного решения. |
| manifest `short_name: 'Ties Break'` | `Ties Break` | Короткая марка и подпись иконки. |
| manifest `description: 'Raise a tennis star: an honest career simulation.'` | `Вырастите теннисистку – без лёгких побед и бесконечных денег.` | Рекламная фраза, не системное обещание. Короче дословного `честный симулятор карьеры`, но следует проверить, не слишком ли обещает невозможность лёгкой победы. Более буквальный запасной вариант: `История теннисной карьеры – матчи, взросление и семейные решения.` |
| отсутствующий HTML `meta description` | Та же выбранная фраза, если метатег будет добавлен | Не создавать вторую рекламную версию случайно. |
| `theme_color`, `background_color`, icons, service-worker cache | Без перевода | Это данные/оформление, не текст для пользователя. |

`vite-plugin-pwa` генерирует **один** manifest из конфига. Если выбор языка возможен в одном установленном приложении, статическая русская `description` покажется и английскому пользователю. Поэтому технической ветке нужно решить отдельно: локализованный manifest/отдельные entry points либо нейтральный английский брендовый manifest до появления настоящей языковой выдачи. Не менять глобальную метку языка на `ru` при английском содержимом.

Предлагаемая страница для русского режима: `PRIVACY.ru.md` или отдельный русскоязычный маршрут с эквивалентным текстом. Текущий английский `PRIVACY.md` не перезаписывать: на него ещё может вести английская версия приложения и публичная ссылка.

### Редакторские ограничения для политики

- `Всё остаётся на устройстве` звучит слишком абсолютно рядом с честным замечанием про журналы GitHub Pages. Поэтому лид уточнён до **игровых данных**. Это смысловое уточнение, не ослабление обещания.
- Удаление приложения в разных браузерах/ОС может не удалить связанное хранилище автоматически. Русская строка говорит `вместе с его данными`; перед релизом проверять формулировку на целевых платформах и исходный английский текст на ту же точность.
- Ссылка `GitHub Issue` сохраняет адрес `https://github.com/letulip/ties-break/issues`; локализуется подпись, не URL.
- Если в технической ветке появятся аналитика, облако или сторонний шрифт, **обе** языковые политики и эта строка About нуждаются в ревизии до релиза.

## 3. Маршрут и LQA

1. В русской вкладке About подпись ссылки – `Конфиденциальность` (RU-13B); она открывает русскую страницу. Английская вкладка продолжает открывать английскую.
2. Проверить установленное приложение на Android и iOS: название под иконкой, описание в установочном приглашении (где браузер его показывает), язык доступного текста, offline-страницу и отсутствие английской политики по русской ссылке.
3. Не обещать перевод системного браузерного диалога установки: его язык выбирает браузер/ОС, не игра.
